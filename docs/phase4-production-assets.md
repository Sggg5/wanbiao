# Phase 4 production assets

Branch: `phase4/production-assets-9015`

This branch replaces the source-derived 9015 prototype layers with standalone 1200×1600 transparent WebP assets.

Golden sample target:
- Miyota 9015
- Classic 39 case
- Midnight Blue / Obsidian Black / Silver Grain dials
- Dauphine hands
- Steel bracelet
- Crystal highlight

All production layers share the same 1200×1600 coordinate system. The default build should pass `npm run validate:assets:strict` before merge.
